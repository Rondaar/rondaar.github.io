Personal Projects

Füel

Co-op game · in development · 2026

A co-op game for up to four players, built on FishNet. You escort a huge mechanical spider through a foggy desert junkyard and keep it running on the trash you pick up along the way, climbing hand over hand with a separate stamina for each hand. The game was inspired by co-op friendslop games like PEAK, and by indie titles with great atmosphere and mechanics, like White Knuckle and Rain World.

The code is built on VContainer, R3 and UniTask. I write it with Claude, which also helps with planning, tasks and documentation. The architecture still follows a few strict rules: game logic in plain C# with unit tests, MonoBehaviours only as views (MVP). Procedural animation for the player and the mobs, mob AI on behaviour trees.

I do the code, game design and tech art. Environment design, UI and 2D art by Patryk Borowiec. (Unity)
